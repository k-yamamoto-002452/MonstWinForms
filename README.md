# MonstWinForms

Unityを使わずに、Visual StudioのWindows Formsで動くモンスト風ゲームです。

## 使い方

1. Visual Studioで「新しいプロジェクト」を選ぶ
2. 「Windows Forms アプリ」を選ぶ
3. プロジェクト名を `MonstWinForms` にする
4. 自動生成された `Program.cs` の中身を、このフォルダの `Program.cs` に置き換える
5. 実行する

## 操作方法

マウスで画面をドラッグし、離すとプレイヤーが発射されます。
敵に当たるとHPが減り、HPが0になると敵が消えます。
